Courier Optimization — Deep Q-Network

SHEET 03 / 07 — CASE STUDY
SOLO BUILD · PYTORCH · REINFORCEMENT LEARNING

A real-time courier assignment policy learned by trial and error

A reinforcement-learning system that assigns couriers to orders as they arrive, instead of relying on static rules. A DQN agent learns a cost-aware, load-balanced policy from historical assignment data — weighing distance, courier availability, and open workload — and is evaluated against real historical outcomes with a held-out test set.

GitHub repo →

PREPROCESSHaversine dist. + cost
